## 横並びの組み合わせ例

合計 width が **900px 以内**に収まる組み合わせを目安にする（kintone の標準コンテンツ幅）。

### 3 フィールド横並び（合計 750）

```
[SINGLE_LINE_TEXT (200)] [SINGLE_LINE_TEXT (300)] [SINGLE_LINE_TEXT (250)]
```

### 2 フィールド横並び（合計 700）

```
[SINGLE_LINE_TEXT (200)] [SINGLE_LINE_TEXT (500)]
```

### ステータス系 3 連（合計 600）

```
[DROP_DOWN (200)] [DROP_DOWN (200)] [NUMBER (200)]
```

### 短項目 4 連（合計 700）

```
[NUMBER (150)] [NUMBER (150)] [NUMBER (200)] [DROP_DOWN (200)]
```

## 一貫性のための設計ルール

1. **本文フィールドは同一 width に揃える**（通常 700）。同じセクション内でバラバラだと読みにくい。
2. **LABEL / HR は本文 width と揃える**（折返し回避）。
3. **識別情報の 1 行目は「固定幅 ID + 可変幅 Name」**（例: 200 + 500 = 700）。
4. **DROP_DOWN は 200 基準**。長い選択肢がある場合のみ 300 等に広げる。
5. **金額・日付・ID 等の「短項目」は 150〜200 の範囲**で統一。

この制約でフォーム全体に統一感が出る。
