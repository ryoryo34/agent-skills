# デフォルト評価基準

## 評価軸（6軸 × 0-100）

### 1. 構造的網羅性（Structural Coverage）
正解と同じセクション・項目が含まれているかを評価する。

- 100: 正解と同じセクション構造を完全に網羅
- 75: 主要セクションは含まれるが一部欠落
- 50: 半分程度のセクションしか含まれない
- 25: 大幅にセクションが不足
- 0: 構造的に全く異なる

### 2. 内容の正確性（Content Accuracy）
事実・数値・論理が正解と一致しているかを評価する。

- 100: 事実・数値・論理が全て正確
- 75: 軽微な不正確さが1-2箇所
- 50: 重要な不正確さが複数
- 25: 多くの箇所で不正確
- 0: 内容が根本的に誤り

### 3. 具体性（Specificity）
抽象的な記述ではなく、具体的な数値・手順・根拠があるかを評価する。

- 100: 全ての主張に具体的な数値・手順・根拠がある
- 75: ほとんどの主張が具体的
- 50: 具体的な記述と抽象的な記述が混在
- 25: ほとんどが抽象的な記述
- 0: 全て抽象的・定性的

### 4. 整合性（Consistency）
文書内の数値・主張に矛盾がないかを評価する。

- 100: 文書内に矛盾なし
- 75: 軽微な不整合が1箇所
- 50: 目立つ矛盾が複数
- 25: 重大な矛盾が存在
- 0: 文書全体で整合性が取れていない

### 5. 実用性（Actionability）
読み手が実際にアクションを取れる品質かを評価する。

- 100: 読み手がそのまま実行できるレベル
- 75: 若干の補足が必要だが概ね実行可能
- 50: 追加情報がないと実行困難
- 25: 実行には大幅な追加作業が必要
- 0: 実行不可能

### 6. フォーマット準拠（Format Compliance）
正解のフォーマット・トーン・スタイルに従っているかを評価する。

- 100: フォーマット・トーン・スタイルが完全一致
- 75: ほぼ準拠、軽微な差異
- 50: 部分的に準拠
- 25: 大幅にフォーマットが異なる
- 0: 全く異なるフォーマット
