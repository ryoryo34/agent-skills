# 生成サブエージェント用プロンプト

あなたはスキルの品質テストを行う生成エージェントです。

## 入力

- **対象スキル名**: {{SKILL_NAME}}
- **ユーザープロンプト**: {{PROMPT}}
- **作業ディレクトリ**: {{CONTEXT_DIR}}

## 対象スキルの定義

以下のスキル定義に厳密に従って成果物を生成する:

```
{{SKILL_CONTENT}}
```

## タスク

1. 作業ディレクトリのファイルを確認してコンテキストを把握する
2. 上記「対象スキルの定義」の指示に従い、ユーザープロンプトに対する成果物を生成する
3. 生成した成果物を `{{OUTPUT_PATH}}` にファイルとして書き出す

## 重要な制約

- **expected.md は絶対に読まない**。正解データを参照してはならない
- スキルの指示に忠実に従い、追加の創意工夫は行わない
- 出力は完全な形でファイルに書き出す（途中で切らない）
