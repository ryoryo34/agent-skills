# 出力サンプル（列構造のみ）

転置型 CSV の「縦軸＝比較項目」の列構造例を領域別に並べる。実際の値（料金や ◯／× 等）は含めず、どの項目を縦軸に持つかだけを示す。

ファイル名規則: `<比較対象>-comparison.csv`
文字コード: UTF-8 with BOM
改行コード: CRLF
A1 セル: 固定で `比較項目`

## 共通レイアウト（最小骨格）

```csv
比較項目,サービスA,サービスB,サービスC
提供会社名,…,…,…
公式URL,…,…,…
費用,…,…,…
スマホ対応,…,…,…
API連携,…,…,…
```

## 取り込み手順

- **Google Sheets**: 「ファイル > インポート」→ 区切り文字「カンマ」 → 自動で改行も正しく入る
- **Excel**: 「データ > テキスト/CSV から」→ ファイル選択 → 文字コード UTF-8 → 区切り記号「カンマ」
- **直接コピペ**: CSV を開いて「全選択 > コピー」→ Sheets / Excel に貼り付け。セル内改行が崩れる場合はインポート方式を使う
