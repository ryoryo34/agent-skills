# CSV フォーマット規則

転置型比較表を CSV で出力するときの厳守ルール。スプレッドシート（Excel / Google Sheets）に貼り付けても崩れない形にする。

## クォーティング規則

- **セル内改行が必要なセル**（費用欄が典型）：セル全体をダブルクォートで囲み、内側は実改行（`\n` ではなくリアルな改行文字）
- **カンマを含むセル**（例：`50,000円`、`月額 3,000円〜`）：セル全体をダブルクォートで囲む
- **ダブルクォートを含むセル**：`""` でエスケープ
- **改行コード**：CRLF（`\r\n`）が安全（Excel / Google Sheets 両方で確実に行区切りとして認識される）
- **文字コード**：UTF-8 with BOM（`\xEF\xBB\xBF` を先頭に付与）。Excel で日本語が文字化けしないため
- **末尾**：最終行のあとにも改行を 1 つ入れる
- **A1 セル**：固定で `比較項目` とする（表記ゆれ防止）

## Python での書き出し（推奨）

```python
import csv
with open("comparison.csv", "w", encoding="utf-8-sig", newline="") as f:
    writer = csv.writer(f, quoting=csv.QUOTE_MINIMAL, lineterminator="\r\n")
    writer.writerow(["比較項目", "サービスA", "サービスB", "サービスC"])
    writer.writerow(["提供会社名", "…", "…", "…"])
    writer.writerow([
        "費用",
        "月額 X円〜\n初期費用 X円\n最小ユーザー数 X\n契約方法 年間契約",
        "…", "…",
    ])
```

- `encoding="utf-8-sig"` → BOM 付き
- `csv.QUOTE_MINIMAL` → カンマ／改行／クォートを含むセルだけ自動でクォート
- `lineterminator="\r\n"` → CRLF

## Bash heredoc は最終手段

費用欄のような複数行セル・カンマ含みセルがある場合は heredoc だと壊れやすい。基本は Python の `csv` モジュールを使う。

シンプルな表（複数行セル無し）なら heredoc でも OK：

```bash
cat > comparison.csv <<'CSV'
比較項目,Sansan,ホットプロファイル,SKYPCE
提供会社名,Sansan株式会社,株式会社ハンモック,Sky株式会社
公式URL,https://jp.sansan.com/,https://www.hammock.jp/hpr/,https://www.skypce.net/
スマホ対応,◯,◯,◯
API連携,◯,◯,△（プラグインあり）
CSV
```

## 値の表記凡例

| 記号 | 意味 |
|------|------|
| `◯` | 対応／可能／提供あり |
| `△` | 条件付き・部分対応（例：「△（プラグインあり）」「△（別料金、メルマガ送信のみ）」など補足を括弧で添える） |
| `×` | 非対応 |
| `不明` | 公開情報で確認できなかった（「不明（おそらく可能）」のように推測を補足してよい） |

## 費用欄の書き方

費用は項目が多いので、セル内改行（CSV ではダブルクォート内の実改行、Sheets セル内でも改行として認識される）で内訳を並べる。最低 4 つを含める：

- 月額（プラン名やレンジを併記。「実質X円」と運用上の実勢を添えてよい）
- 初期費用（不明なら「不明」）
- 最小ユーザー数（なければ「なし」）
- 契約方法（年間契約／月額契約／個別見積もり）

### 「個別見積もり」と「不明」の使い分け

| ケース | 表記 |
|-------|------|
| 公式サイトに「料金は要問い合わせ」「お見積もり制」と**明示** | `個別見積もり`（B2B SaaS では一般的、× ではない） |
| 公式サイトに料金体系の手がかりが何もない | `不明` |
| 内訳ごとに混在（例：プラグイン費用は明示、本体は要見積もり） | 内訳ごとに使い分け |

混在例：

```
費用,"個別見積もり
（kintone連携プラグインは年額 50,000円）",…,…
```

## ハマりどころ

- Excel で開いて文字化けする → UTF-8 with BOM になっているか確認。なっていなければ `iconv -f UTF-8 -t UTF-8//IGNORE` で付け直す
- セル内改行が単なる空白に変換される → ダブルクォートで囲み忘れている、または `\n` 文字列をそのまま書いている（実改行にする）
- カンマで分割されすぎる → 金額の `50,000円` 等にダブルクォートを付け忘れている
