# 追加項目カタログ（領域別）

要望の領域がはっきりしている場合に、ヒアリングで提示する追加項目の参考リスト。
ここに無い領域でも、必須6項目から派生して類推できる項目を提示してよい。

## 名刺管理サービス

| 項目名 | 説明 | 値の例 |
|--------|------|-------|
| 利用制限 | 月間スキャン枚数・ユーザー単位制限 | 無制限／月20枚/ユーザー／個別見積もり |
| 企業 / 人物 名寄せ | 同名・同社レコードの自動マージ | ◯ / × |
| 法人番号 | 法人番号での自動付与・連携 | ◯ / 不明 |
| 上場 / 非上場区分 | 企業属性情報の付与 | ◯ / 不明 |
| 独自タグの設定 | カスタムタグでの分類 | ◯ |
| メールマーケティング | メルマガ・配信機能の有無 | ◯ / △（別料金） |
| OCR 精度 | 公開されている読み取り精度や補正方式 | 99%／手動補正併用 |
| kintone 連携 | プラグイン or API での kintone 連携 | ◯（プラグイン）／△（API のみ） |
| 多言語対応 | 英語・中国語名刺の読み取り | ◯ |

|--------|------|
